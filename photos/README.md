# 📷 回忆照片（photos/ 文件夹）

把 10 张回忆照片命名后放在这里：

| 文件名 | 对应回忆 |
|--------|----------|
| `memory1.jpg` | 第1段回忆 |
| `memory2.jpg` | 第2段回忆 |
| `memory3.jpg` | 第3段回忆 |
| `memory4.jpg` | 第4段回忆 |
| `memory5.jpg` | 第5段回忆 |
| `memory6.jpg` | 第6段回忆 |
| `memory7.jpg` | 第7段回忆 |
| `memory8.jpg` | 第8段回忆 |
| `memory9.jpg` | 第9段回忆 |
| `memory10.jpg` | 第10段回忆 |

支持格式：`.jpg` `.png` `.webp`

---

修改回忆文字/日期：打开 `index.html`，找到 `const MEMORIES = [...]` 修改。
