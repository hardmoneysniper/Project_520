# 🖼️ 拼贴照片（collage/ 文件夹）

把你们所有的照片（100张以上）放在这里，按顺序命名：

```
1.jpg
2.jpg
3.jpg
...
100.jpg
101.jpg（可以继续加）
```

这些照片会被拼成 **"I LOVE U"** 的文字形状显示在最后一页。

放完之后，打开 `index.html`，把这一行改成实际照片数量：

```javascript
const COLLAGE_COUNT = 100;  // ← 改成你放的照片总数
```

**小贴士**：可以用以下批量重命名方法——
- Windows：选中所有照片 → 右键重命名 → 输入 `1` → 回车，系统会自动命名为 1(1).jpg, 1(2).jpg...（之后再手动去括号）
- 或者用 PowerShell 脚本一键重命名

支持格式：`.jpg` `.png` `.webp`
